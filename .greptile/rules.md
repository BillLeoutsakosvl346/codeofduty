## Code of Duty ownership declarations

Every product pull request contains one `CODE_OF_DUTY_CONTRIBUTION_V1` JSON block in its description.

- Treat the declaration as a claim to review, not as truth.
- Compare declared `features` with `catalog/features.json` and the changed files.
- Compare contributor roles with evidence present in the PR description, code, tests, and review discussion.
- Never infer ownership from who pushed the branch, authored commits, or opened the PR.
- Do not invent contributors or rewrite the declared numeric split.
- If evidence and declaration disagree, leave a concise blocking finding for a human reviewer.
- If the declaration is plausible, state that it is consistent with the visible diff; do not claim to have verified offline work.
